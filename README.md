# Pose Studio

A 3D animation editor for the Unreal Engine 5 Manny rig that runs in the browser.

**Open it:** https://iirg4x.github.io/pose-studio/

## What it does

- Pose Manny with IK and FK controls, and pose props and the camera too.
- Keyframe on a timeline, edit curves, and stack animation layers.
- Work on first-person and full-body actions, with a preview pairing between them.
- Reset any control to the skeleton's real rest pose.
- On desktop, the scene fills the window. Panels are optional and can be docked or left floating.
- On phones and tablets, use touch tools, with pen support.
- Record animations to video.

## Your data

This repository holds only the built app and its built-in models. Your projects never leave your device. They stay in the browser's local storage, or in `.pose` files that you save yourself.

## Install and use offline

- **iPhone / iPad:** open the link in Safari, tap Share, then Add to Home Screen.
- **Android / desktop Chrome or Edge:** use the browser's Install option.

After the first load the app works offline. Updates download in the background. They apply only after you close and reopen every Pose Studio window, so an update never interrupts an edit. Save `.pose` files as backups.

# Pose Studio

Installable touch animation studio. The published files contain the app and its built-in resources only. Projects stay in local browser storage or in files you explicitly save.

On iPhone, open the app in Safari, tap Share, then Add to Home Screen. Keep Open as Web App enabled when available. Wait for “Ready for offline use” in the Project menu’s Install Studio / app status panel before going offline.

Updates download in the background and apply after all Pose windows are closed and reopened. Save project files separately as a backup.
